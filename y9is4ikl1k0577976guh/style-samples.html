STAR LION 2 · LEON STYLE SAMPLES

Test page only. Nothing here is in the game yet. Each cell is drawn with the game's own dialogue-box code (panel, bust card, pixel font) at the game's bust size (60×60) with the in-game sprite on the firefly-meadow background.
Design decisions (Simba), applied to these samples only:
• Adult Leon: no crown, no necklace by default. The crown stands for accepting responsibility and accountability, so it is earned later.
• Teen Leon: no face paint by default. Paint is the optional DRESS TO IMPRESS look for the deeper Ch2 date dress-up (ear hoops kept; also on the default here).
• Cub Leon unchanged: golden, small red-auburn tuft, big warm eyes.
• Original designs, SFW. The teen blowout is a hairstyle archetype only.
